This directory contains the editable Turkish Open Logic locale and cumulative
OLP-0062 driver.

The source must be overlaid on the official Open Logic Project repository at
commit 9620cc73f9c8e0ad003c514a5d3748f29611c4c0. The pinned build script in
../build/BUILD.ps1 performs that operation in a fresh temporary checkout.

Generated TeX intermediates, rendered-page images, credentials, caches,
unrelated languages, and workbench Git metadata are intentionally excluded.
